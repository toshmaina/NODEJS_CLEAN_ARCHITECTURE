# Node.js TypeScript Express API with 3-Layer Architecture

This project is a Node.js API built with TypeScript and the Express framework. The API follows the 3-layer architecture pattern, which separates concerns into distinct layers: **Controller**, **Service**, and **Data Access**.

## Prerequisites

Before you begin, ensure that you have met the following requirements:

- [Node.js](https://nodejs.org/) (>= 16.x)
- [npm](https://www.npmjs.com/) (>= 7.x)
- [TypeScript](https://www.typescriptlang.org/) (>= 4.x)

## Installation

Follow these steps to get the project up and running on your local machine.

1. Clone the repository:
   ``` bash
   git clone https://github.com/toshmaina/NODEJS_CLEAN_ARCHITECTURE.git
   cd your-repository```
2. Install dependencies:
   ```bash npm install```
3. Build Project:
   ``` bash npm run build```
4. Start the API server:
 ``` bash npm run dev ```
The API should now be running at http://localhost:8080.
