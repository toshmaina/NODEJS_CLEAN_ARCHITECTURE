API Documentation

Welcome to our API documentation!

This API provides a simple RESTful interface for interacting with our application. It allows you to perform CRUD (Create, Read, Update, Delete) operations on our data.

The API is built using Node.js and Express.js, and is deployed on Vercel.

Below are the available endpoints:

  • GET /api/data: Retrieves a list of all data
  • POST /api/data: Creates a new data item
  • GET /api/data/:id: Retrieves a single data item by ID
  • PUT /api/data/:id: Updates a single data item by ID
  • DELETE /api/data/:id: Deletes a single data item by ID
